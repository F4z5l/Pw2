CodeXStudys — Vercel deployment

This edited project removes the pnpm catalog/workspace dependency issue and includes Vercel settings.

Deploy:
1. Upload the contents of this folder to a new GitHub repository.
2. Import that repository in Vercel.
3. Keep the Root Directory as ./.
4. The included vercel.json supplies the build command and output directory.
5. Click Deploy.

The repository root must contain package.json, index.html, src/, public/, vite.config.ts, tsconfig.json, and vercel.json.
